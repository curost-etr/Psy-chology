# 本地意图模型：训练与使用

已完成第一版 CPU 训练，网页推理不需要 Python、GPU 或远程模型服务。实现使用 Node.js 内置模块，无新增运行依赖。模型是字符 TF-IDF + 多分类逻辑回归，负责选择疏导意图；回复来自现有话术库。

## 已训练版本

版本：`c7d1f3bb68df`。原型语料 210 条：训练 140、开发 35、测试 35。七类均衡，每类分别为 20 / 5 / 5 条。

所有初始语料由 AI 助手编写，未收集真实用户对话，未经过独立双人或临床标注。划分分别编写，并检查规范化重复、近似重复和显式分组泄漏；同一来源的语言风格及场景相似性仍会造成偏差。这版用于验证训练和接入流程，不能据此推断真实用户表现。

| 保留测试集指标 | 结果 |
| --- | --- |
| 七类 macro-F1（拒识前） | 0.9137 |
| 七类准确率（拒识前） | 32/35，91.43% |
| 原关键词基线 macro-F1（纯文本、不含画像） | 0.6235 |
| 被模型接收并选择具体意图 | 22/35，62.86% |
| 接收部分正确率 | 21/22，95.45% |
| `other` 被误接收为困扰 | 0/5 |

接收覆盖率的分母包含 `other`，因此 `other` 正常拒识也会降低覆盖率。小样本结果的不确定性很大，0/5 不代表范围外输入不会误接收。当前未进行外部独立评测、真实用户研究或风险识别准确率评测。

三条分类错误涉及“想睡觉恢复精神”“是否考公”“拒绝同学要求”。错误明细及各类指标保存在 `artifacts/c7d1f3bb68df/metrics.json`。本轮没有根据保留测试集修改模型；以后若针对这些错误训练新版本，应另外准备未见测试样本。

## 运行

在项目根目录运行：

```powershell
npm run train
npm run test:ai
npm start
```

`train` 会验证数据、只用训练集拟合词表与权重、在开发集选择参数和阈值，最后评测测试集，保存模型和指标，通过工程验证后同步静态发布资源。训练是确定性的全量重新拟合，不是大语言模型断点续训。指标达标仅记录为研发目标结果，不代表获准临床使用。

运行成功后打开 `http://localhost:3000`，现有对话在后端聊天 API 不可用时使用意图模型。Netlify 文件夹现已同步完整最新前端，包含对话画像、聊天、问卷评估和意图模型；静态部署时聊天使用浏览器回退路径。这里只生成可部署文件，没有向 Netlify 发布。

静态页面需通过 HTTP 服务访问，不能依赖双击 `file://` 加载模型。Netlify 根路径使用 302 跳转到 `/public/index.html`，确保相对脚本和模型地址正确。

已有 Playwright 环境时可运行 `node training/browser-check.cjs`，脚本使用本机 Chrome，临时 HTTP 服务仅监听 `127.0.0.1`，测试后关闭。浏览器检查不需要外部模型网络。

## 训练自己的数据

初始数据定义在 `seed-data.cjs`，每次训练的完整 JSONL 快照、划分清单、模型、指标保存在 `artifacts/<数据版本>/`。不要把含真实用户信息的数据或整个 training 目录复制到静态站点。发布目录仅包含权重、词表、推理代码和话术配置；权重与词表也应在引入真实语料后检查隐私。

自有 JSONL 每行结构：

```json
{"id":"u001-01","text":"复习资料太多不知道先看什么","intent":"task_start_block","group_id":"user-001","split":"train","source":"consented_anonymous","training_allowed":true,"annotation_status":"reviewed","risk_review":"none"}
```

将每个用户、会话、场景及其近似改写保持在同一集合，人工完成分组与标注；脚本验证显式分组和近似重复，不能自动知道两段文本是否来自同一人。非初始人工编写数据必须标为 `reviewed`。每个集合必须包含七类，语料不能重复，未授权记录会被拒绝。

```powershell
node training/train.cjs --data training/data/reviewed.jsonl
node training/verify.cjs
node training/sync.cjs
```

自定义训练会更新 `public/models/intent-model.json`；同步前查看 `training/latest.json` 指向的指标报告。产物目录按完整数据哈希标识；修改训练算法时应另保留版本目录，避免覆盖同数据的历史实验。上线使用哪一版由实际评测决定，必要时从历史 `model.json` 恢复并重新验证、同步。

## 推理与回退

- Unicode NFKC、转小写、空白折叠；提取 1～3 字符片段，使用训练集 IDF 与 L2 归一化。
- 模型及阈值在 `public/models/intent-model.json`，Node 与浏览器共用 `public/intent-model.js`，避免导出公式不一致。
- 最高概率不足、前两类接近、预测为 `other`、空输入或过长输入会拒识。概率不代表心理风险概率。
- 风险提示优先于意图分类；这些规则仍是有限的关键词规则，存在转述、否定和隐喻误判，需继续做专业复核。
- 模型加载失败回退关键词；模型正常但拒识时进入澄清，不使用关键词强行覆盖。
- Netlify 的新入口不保存或上传输入；本地完整页面保留原有聊天记录与后端请求行为。

下一轮优先补充经授权、独立复核的真实表达和外部测试集，再决定是否需要更大的中文编码器或生成式模型。
